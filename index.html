Every value on the right mirrors a real address in the P1's RAM, so a dump from this page can be diffed nibble-for-nibble against the real ROM running under emulation — which is how the rules behind it are checked, rather than by assertion. Hover a field's name or address for what it means; click its value to poke it. Sprites are original drawings, not the Bandai originals. A cycles the icon cursor, B selects, C cancels (or the A / B / C keys, or → / Enter / Esc) — the device's own cursor, icon order and dispatch table, not an invention of this page. Two things here cannot match a real device, and both are this page having no emulator beside it. The guessing game reads 0x05A, a counter the hardware's programmable timer advances thousands of times a minute, so a game played here is the right computation on a guessed input. And where the clock interrupt lands inside a main-loop pass decides a handful of collisions each minute that a model with a one-minute time base cannot see, so a long run here drifts from a real one at those moments. The test harness replays both from the ROM itself; the page has only the guess.
